Local computer (recommended)
How to use Local mode
  1. Download YouTubeToCommonsAgent.exe from here.
  2. Run it once. The agent automatically registers itself with Windows.
  3. Return to this page and click Pair local agent.
  4. If your browser asks whether it may open YouTubeToCommons Agent, click Open.
  5. After pairing, choose Audio, Video, Thumbnail, or Frame. The YouTube download will run on your computer using your own IP address.

You do not need Python, yt-dlp, or FFmpeg installed separately when using the packaged EXE.

Used only for this server-side download.
