Download method:

Do not use an untrusted public proxy.
Local computer (recommended)
Option 1: Windows (Ready-to-use .exe)
  1. Download YouTubeToCommonsAgent.exe from here.
  2. Run the app. It will register automatically.
  3. Click Pair local agent below.
Option 2: Mac / Linux / Python Script
  1. Download agent.py from the GitHub repository.
  2. Install required libraries: pip install requests yt-dlp
  3. Install FFmpeg (e.g., brew install ffmpeg on Mac or sudo apt install ffmpeg on Linux).
  4. Run the script in your terminal: python3 agent.py
  5. Click Pair local agent below and manually paste the generated 6-digit code into your terminal.
